# Project Task:

## I. Challenge: Celebration and Event Planner

*   **Core Challenge**: Create an AI-powered application to simplify complex event planning (weddings, birthdays, community events).
*   **Key Objectives**:
    *   Move beyond simple ideation to practical management (budgeting, timelines, vendor coordination).
    *   Focus on user constraints (budget, guest count, preferences) rather than generic suggestions.
    *   Enable dynamic plan updates when inputs (e.g., budget or dates) change.
*   **Development Advice**: Start with a specific user persona and a defined problem rather than building all features at once. Ensure the AI acts as a coordinator, providing tradeoffs and alternatives rather than making arbitrary decisions.


## II. Challenge Expectations:
* 
	* Ability to build a smart, dynamic assistant
	* Logical decision making based on user context
	* Practical and real-world usability
	* Clean and maintainable code


## III. Evaluation Criteria:
*   Code quality and problem statement alignment are the highest-weighted parameters; other factors include security, efficiency, testing, and accessibility.
    * Code Quality – structure, readability, maintainability
	* Security – safe and responsible implementation
	* Efficiency – optimal use of resources
	* Testing – validation of functionality
	* Accessibility – inclusive and usable design
	* Problem Statement Alignment – relevance to the stated problem
	
## IV. Submission Guideline:
*   **Data Usage**: Use real-time data or realistic inputs for GenAI queries; avoid hardcoded dummy data for actual user-facing functionality.
*   **Video Submission**: Should be a walkthrough of screens and functionalities to ensure evaluators can see the project working even if API credits expire.
*   **Code Quality**: Avoid hardcoding sensitive information like passwords or API keys directly in the codebase; review evaluation reports to iterate and improve code.

* Code submission must include:

	* A public GitHub repository link
	* A README explaining:
		* Your chosen vertical
		* Approach and logic
		* How the solution works
		* Any assumptions made
